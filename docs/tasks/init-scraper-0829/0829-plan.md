# Plan: 第一階段 - 爬取台塑油價 (Phase 1)

## Step 1: 環境與套件準備
- 透過 pip 安裝 `requests` 與 `beautifulsoup4`。
- 建立主程式檔案 `scraper.py`。

## Step 2: 網頁請求模組
- 在 `scraper.py` 中撰寫請求邏輯，使用 `requests.get` 獲取目標網址的 HTML 原始碼。
- 檢查 Response 狀態碼，確保網路連線正常。

## Step 3: DOM 解析模組
- 使用 `beautifulsoup4` 解析 HTML。
- 觀察網頁結構，定位包含油價資訊的 Table 或 Div 元素。
- 提取「生效日期」與各油品之「價格」。

## Step 4: 資料格式化與驗證
- 將提取出的資料整理成清晰的 JSON / Dictionary 結構。
- 在本地端執行並印出，以進行 Developer Validation。
